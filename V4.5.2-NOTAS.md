# ENIGMA OS V4.5.2 — Acesso ao aparelho na OS

- Entrada de OS agora registra: sem senha/não informada, PIN numérico, senha alfanumérica ou padrão 3×3.
- Padrão pode ser desenhado com mouse ou toque.
- PIN e senha ficam mascarados na entrada, com botão Mostrar/Ocultar.
- Na OS aberta, a credencial fica recolhida por padrão e exige ação para visualizar.
- Credencial não foi adicionada às impressões.
- Dados são armazenados dentro do JSON `aparelho` já existente; não exige SQL nem alteração de schema.
- Demais módulos permanecem iguais à V4.5.1.
