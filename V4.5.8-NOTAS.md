# ENIGMA OS V4.5.8 — Películas: cadastro simples e automático

- Para película, basta escrever UMA referência no campo Nome (ex.: `Película 3D iPhone 13`).
- O campo manual de compatibilidade deixa de ser necessário para películas.
- O cadastro mostra automaticamente quantos modelos compatíveis foram encontrados e quais são.
- PDV encontra o mesmo produto físico pesquisando qualquer modelo compatível da Tabela de Películas.
- Estoque antigo continua funcionando sem recadastro, inclusive nomes que já possuem vários modelos.
- Corrigido o algoritmo de associação para não usar marca/palavras genéricas isoladas (ex.: `iPhone`), reduzindo falsos positivos.
- Um único saldo físico por película; compatibilidades não duplicam estoque.
- Sem SQL novo e sem alteração de estrutura no Supabase.
