# ENIGMA OS V4.5.7 — Películas com compatibilidade automática

- Usa `pelicula_grupos` como fonte única de compatibilidade.
- PDV pesquisa produtos do estoque também por TODOS os modelos compatíveis do grupo.
- Estoque pesquisa da mesma forma.
- Funciona com películas já cadastradas e novas, sem duplicar saldo.
- Não grava uma película por modelo: um produto físico continua sendo um único saldo.
- Não altera quantidades existentes.
- Se a base de compatibilidade estiver temporariamente indisponível, nome/SKU/compatibilidade manual continuam funcionando.

Sem SQL novo: utiliza as tabelas de películas já existentes.
