# ENIGMA OS V4.4.1 — Segurança, Login e Níveis de Acesso

- Login real via Supabase Auth.
- Sessão com access token e refresh token.
- Bloqueio do sistema para usuários sem perfil ativo.
- Quatro perfis: administrador, gerente, vendedor e técnico.
- Menu lateral/mobile filtrado por nível de acesso.
- Usuário e função aparecem na interface.
- Logout disponível.
- Requisições ao banco passam a usar o token do usuário autenticado.
- SQL cria tabela enigma_usuarios, funções de permissão, RLS e auditoria.
- Auditoria automática registra INSERT/UPDATE/DELETE nas tabelas operacionais.
- Dados sensíveis financeiros ficam restritos a administrador/gerente.
- Configurações ficam restritas ao administrador.

IMPORTANTE: execute SUPABASE-V4.4.1-SEGURANCA.sql antes de publicar a versão.
Depois crie os usuários no Supabase Authentication e cadastre seus perfis conforme instruções do SQL.


Correção V4.4.1: scripts de RLS e auditoria agora detectam o tipo da relação e ignoram views automaticamente.
