# ENIGMA OS V4.0 — Fluxo Operacional Conectado

Primeira etapa estrutural da V4.0.

- Central de Atendimento redesenhada como hub operacional.
- Busca unificada por cliente, telefone, aparelho e número da OS.
- Clientes encontrados aparecem junto ao histórico operacional.
- Indicadores rápidos: em andamento, aguardando aprovação, em reparo e prontas.
- Fluxo visual: Cliente → OS → Diagnóstico → Orçamento → Aprovação → Reparo → Pagamento → Entrega → Pós-venda.
- Jornada visual adicionada dentro da própria OS para orientar o operador.
- Etapas da jornada levam às áreas correspondentes da OS.
- Campo cliente_id preparado no mapeamento da OS para ligação persistente com clientes.

IMPORTANTE
Esta V4.0 inicia a conexão estrutural sem remover os fluxos já validados.
Para persistir cliente_id diretamente em ordens_servico, execute SUPABASE-V4.0.sql.
