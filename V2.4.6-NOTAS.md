# ENIGMA OS V2.4.6 — Hotfix definitivo da Timeline

## Corrigido
- Tela preta ao registrar uma oferta.
- Causa confirmada pelo Console do navegador: `ReferenceError: React is not defined`.
- A Timeline usava `React.Fragment`, mas o projeto não importa `React` como namespace.
- A renderização foi alterada para não depender de `React.Fragment`.
- Ajuste adicional na consulta de referências de mercado para tornar o filtro `ilike` mais robusto.
