# ENIGMA OS V2.5 — Seminovos + PDV

## Fluxo implementado
- Seminovo disponível recebe preço de venda na própria ficha.
- "Enviar ao PDV" libera a unidade no PDV.
- PDV ganhou a aba "Seminovos".
- Cada seminovo entra como unidade única, identificado por IMEI/serial.
- Venda do seminovo registra a venda normalmente no caixa.
- Após venda, o aparelho muda automaticamente para status `vendido`.
- O mesmo seminovo não pode ser vendido novamente.
- O registro interno guarda valor de venda, forma de pagamento, data e lucro bruto.
- Exclusão de uma venda restaura o seminovo para `disponivel`.

## Banco
Nenhum SQL novo. Preço e dados da venda ficam no JSON `dados` da tabela `seminovos`.
