# ENIGMA OS V4.4.6 — Gestão completa de usuários

Administrador pode:
- editar nome;
- editar usuário/login;
- alterar nível de acesso;
- redefinir senha;
- bloquear/reativar contas.

Proteções:
- administrador não pode bloquear a própria conta;
- administrador não pode rebaixar a própria conta;
- usuário/login duplicado é rejeitado.

IMPORTANTE: esta versão altera a Edge Function `enigma-admin-users`.
Após subir o projeto, faça o deploy da função:
`supabase functions deploy enigma-admin-users`

Não há SQL novo nesta versão.
