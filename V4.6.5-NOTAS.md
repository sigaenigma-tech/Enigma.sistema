# ENIGMA OS V4.6.5 — Fechamento usa venda editada

Correção principal
- Fechamento de caixa não depende mais do estado antigo carregado na tela.
- Antes de fechar, o sistema recarrega diretamente do Supabase todas as vendas ligadas ao caixa.
- Se uma venda foi editada de Dinheiro para Pix ou teve o valor alterado, o fechamento usa a versão atual.

Melhorias
- Botão “Atualizar vendas” na tela do caixa aberto.
- Edição de venda sincroniza `forma_pagamento`, `pagamentos`, `total` e também o lançamento financeiro do PDV.
- Após editar uma venda do caixa aberto, o sistema recarrega as vendas persistidas.
- Se a atualização do banco falhar no momento do fechamento, o fechamento é bloqueado para evitar gravar números divergentes.
- Mantém as correções das versões anteriores.

Sem SQL novo.
