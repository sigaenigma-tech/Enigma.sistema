# ENIGMA OS V4.3 — Aparelhos do Cliente

- Cliente 360° agora agrupa o histórico técnico por aparelho.
- IMEI / serial é usado como identidade principal do aparelho quando informado.
- Aparelhos sem serial continuam agrupados por modelo para manter compatibilidade com dados antigos.
- Cards de aparelho mostram modelo, IMEI/serial, cor, quantidade de OS e última entrada.
- Atalho do aparelho abre sua OS mais recente.
- Nova OS ganhou campo Cor do aparelho.
- Cor é persistida dentro do JSON `aparelho`, sem exigir coluna/tabela nova.
- OS cancelada agora aparece como “não contabilizada” no histórico e na linha do tempo.
- Nenhum SQL novo necessário nesta etapa.
