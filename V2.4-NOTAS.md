# ENIGMA OS V2.4 — Avaliação & Compra de Usados

## Novo módulo
Menu **Avaliação de Usados** com fluxo:
IDENTIFICAR → INSPECIONAR → TESTAR → PRECIFICAR → OFERTA → AQUISIÇÃO.

## Primeira versão funcional
- Cadastro do vendedor.
- Identificação do aparelho, IMEI e serial.
- Nota estética, bateria, procedência e avarias.
- Checklist técnico específico para compra.
- Motor de precificação com faixa de mercado, reparos, custo operacional, margem e reserva de risco.
- Cálculo automático do valor máximo recomendado para compra.
- Registro de oferta e aquisição.
- Termo-base de procedência para futura assinatura.
- Histórico das avaliações no Supabase.
- Primeira aplicação da linguagem visual **ENIGMA UI 2.0**.

## Deliberadamente deixado para a próxima evolução
- Fotos próprias da avaliação conectadas ao Supabase Storage.
- Consulta automática de preço de mercado.
- Assinatura/QR Code do termo de compra.
- Entrada automática no estoque individual de seminovos.
- Impressão/PDF do termo definitivo.

> O texto jurídico exibido nesta versão é uma base operacional e deve ser validado por profissional habilitado antes de uso comercial.
