# ENIGMA OS V3.6 — Base Interna de Compatibilidade

- Tabela de Películas passa a usar base própria no Supabase.
- Cadastro manual de grupos.
- Vários modelos por grupo.
- Editar e desativar grupos.
- Consulta rápida por qualquer modelo cadastrado.
- Cruzamento com películas já existentes no estoque.
- Importador XLSX / XLS / CSV.
- Detecção automática de colunas.

- Contagem de novos grupos, grupos existentes e novos modelos.
- Importação mescla modelos em grupos existentes.
- Exportação da base para CSV.
