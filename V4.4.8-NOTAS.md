# ENIGMA OS V4.4.8 — Correção da impressão da Via do Cliente

Causa encontrada:
- O comprovante chamava `STATUS[...]`, mas essa constante não existe no sistema.
- Isso gerava erro JavaScript antes de chegar em `window.open()`, então o botão parecia não fazer nada.

Correções:
- Status do comprovante agora usa o helper existente `statusInfo()`.
- Abertura da impressão ganhou tratamento de erro.
- Adicionado fallback por iframe caso o navegador bloqueie popup.
- Se houver outro erro de geração, o sistema agora mostra mensagem em vez de falhar silenciosamente.

Não requer SQL e não altera a Edge Function.
