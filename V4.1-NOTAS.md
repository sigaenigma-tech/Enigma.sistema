# ENIGMA OS V4.1 — Cliente Único no Atendimento

- Nova OS começa pela busca de cliente.
- Busca por nome, telefone, CPF/documento ou e-mail.
- Cliente existente é selecionado e seus dados entram automaticamente na OS.
- Cadastro rápido de novo cliente dentro da Nova OS.
- Bloqueio preventivo de duplicidade por telefone.
- Se o telefone já existe, o cadastro existente é selecionado.
- Aparelho e problema ficam bloqueados até um cliente ser vinculado.
- A OS grava cliente_id no banco.
- O mesmo cliente passa a conectar histórico de assistência e PDV.
- Não há SQL novo: usa a coluna cliente_id criada na V4.0.
