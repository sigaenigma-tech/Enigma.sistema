# ENIGMA OS V3.4 — Dashboard Visual / Command Center

- Dashboard redesenhado para uma experiência mais visual e interativa.
- Filtro global de 7, 30 e 90 dias.
- Gráfico de linha/área com evolução diária do faturamento.
- Gráfico circular de formas de pagamento.
- Ranking visual dos produtos mais vendidos com barras.
- Fluxo visual da assistência técnica por etapa.
- Indicador de saúde do estoque com distribuição saudável/baixo/zerado.
- Bloco Insights ENIGMA com alertas e oportunidades acionáveis.
- Indicadores de faturamento, lucro bruto estimado, margem, ticket médio e OS em andamento.
- Financeiro resumido do período.
- Tooltips nativos no gráfico de vendas ao passar o cursor nos pontos.
- Sem novas dependências: gráficos são renderizados com SVG/CSS para manter o projeto leve.
